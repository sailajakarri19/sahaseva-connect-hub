# SahaSeva Connect

A cooperative-owned service marketplace connecting households and institutions with verified cooperative workers.

This project was built with [Lovable](https://lovable.dev).

## Features

- Role-based access for customers, cooperative workers, and admins
- Service booking with transparent pricing and worker-share breakdown
- Worker registration with admin verification
- Emergency service requests
- Demo payment gateway integration (Razorpay) and Google Maps geocoding/routing scaffolds

## Development

```sh
bun install
bun run dev
```

## Built with

- TanStack Start
- React 19 + TypeScript
- Tailwind CSS
- shadcn/ui
